# СвежМаркет

Интернет-магазин продуктов питания с доставкой. Адаптивный сайт на HTML5, CSS3 и ванильном JavaScript с реал-тайм корзиной, поиском и фильтрацией.

## Возможности

- Каталог из **32 товаров** в 8 категориях (овощи, фрукты, мясо, молочные продукты, хлеб, бакалея, напитки, рыба)
- **Поиск в реальном времени** с подсказками и подсветкой совпадений
- **Фильтрация по категориям** без перезагрузки страницы
- **Корзина** с добавлением, изменением количества и удалением товаров
- Сохранение корзины и предпочтений в **localStorage**
- Страница товара с блоком **«Рецепты с этим продуктом»**
- **SEO-оптимизация**: мета-теги, alt-тексты, структурированные данные schema.org
- Адаптивный дизайн для мобильных, планшетов и десктопов

## Структура проекта

```
Pem_07/
├── index.html              # Главная страница
├── product.html            # Страница товара
├── css/
│   ├── main.css            # Базовые стили
│   ├── components.css      # Компоненты UI
│   └── responsive.css      # Адаптивная вёрстка
├── js/
│   ├── storage.js          # Работа с localStorage
│   ├── seo.js              # SEO и schema.org
│   ├── products.js         # Загрузка и рендер товаров
│   ├── cart.js             # Логика корзины
│   ├── search.js           # Поиск с подсказками
│   ├── filters.js          # Фильтрация каталога
│   ├── app.js              # Инициализация главной страницы
│   └── product-page.js     # Страница отдельного товара
└── data/
    ├── products.json       # Данные каталога
    └── products-data.js    # Fallback для открытия через file://
```

## Быстрый старт

### Вариант 1 — локальный сервер (рекомендуется)

```bash
# Активация виртуального окружения (опционально)
source venv/Scripts/activate   # Git Bash
# .\venv\Scripts\Activate.ps1  # PowerShell

# Запуск сервера
python -m http.server 8765
```

Откройте в браузере: **http://localhost:8765**

### Вариант 2 — без сервера

Дважды кликните по файлу `index.html`. Данные загрузятся из `data/products-data.js`.

## Технологии

| Технология | Назначение |
|------------|------------|
| HTML5 | Семантическая разметка |
| CSS3 | Стили, адаптив, анимации |
| JavaScript (ES6+) | Логика без фреймворков |
| localStorage | Сохранение корзины и настроек |
| JSON / schema.org | Данные товаров и SEO-разметка |

## Цветовая палитра

- **Белый** — основной фон
- **Зелёный** (`#2E7D32`) — акцент, кнопки, активные элементы
- **Оранжевый** (`#FF6D00`) — специальные предложения, бейджи

## Модули JavaScript

| Файл | Описание |
|------|----------|
| `storage.js` | Чтение/запись корзины и предпочтений в localStorage |
| `products.js` | Загрузка каталога, рендер карточек и категорий |
| `cart.js` | Добавление, удаление, подсчёт суммы, боковая панель |
| `search.js` | Поиск по названию, описанию и категории |
| `filters.js` | Фильтрация каталога по категориям |
| `seo.js` | Генерация title, description, alt и JSON-LD |
| `app.js` | Точка входа для `index.html` |
| `product-page.js` | Точка входа для `product.html` |
